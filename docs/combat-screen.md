# Экран единоборств

`docs/mini-app.html` — самостоятельный HTML5-файл: CSS, JavaScript и SVG-иконки встроены. Открывается без сборки и без внешних библиотек. В Sites главная страница показывает этот файл в iframe; при переносе в Telegram используйте сам HTML напрямую.

Макет повторяет предоставленные скриншоты, с вручную воссозданными иконками и системным Arial вместо неизвестного исходного шрифта. Системные панели Android исключены. Мобильный экран имеет максимальную ширину 450 px, на широком экране центрируется.

Данные — транскрипция референсов, не проверенное расписание и не текущие коэффициенты. Последний турнир показан только заголовком: участники на скриншоте не видны. Тоталы не выдуманы, отсутствующие значения отображаются тире. Live и результаты пусты до передачи реальных данных. Нижние разделы вне экрана боёв — демонстрационные панели, финансовых операций нет.

## Подключение API

Выбранный провайдер, адрес API и ключи пока не заданы. Нормализуйте ответ на сервере, затем передайте массив в `window.FightScreen.setEvents(events)`. Секретные ключи храните на сервере.

```js
window.FightScreen.setLoading(true);
try {
  const response = await fetch('/api/fights'); // ваш будущий endpoint
  if (!response.ok) throw new Error('Сервис временно недоступен');
  window.FightScreen.setEvents(await response.json());
} catch (error) {
  window.FightScreen.setError(error.message);
}
```

Форма записи:

```json
{
  "id": "unique-id",
  "sport": "mma",
  "status": "prematch",
  "title": "Название турнира и категория",
  "date": "13 СЕНТЯБРЯ В 05:40",
  "fighters": ["Боец 1", "Боец 2"],
  "odds": [1.2, 66, 4.8],
  "totals": {"line": 2.5, "over": 1.8, "under": 2.0},
  "result": "Победитель · Метод · Раунд"
}
```

`sport`: `mma` или `boxing`. `status`: `prematch`, `live`, `finished`. `totals` и `result` необязательны. Время форматирует ваш адаптер под часовой пояс пользователя. Результаты открываются через меню → Результаты. `setEvents` заменяет весь набор, сбрасывает выбор коэффициентов и фильтр даты. `setSport('boxing')` переключает вкладку. `getState()` возвращает текущее состояние.

Telegram SDK и авторизация не подключены: этот этап — дизайн. Для публикации в Mini App потребуется доступный пользователям HTTPS-адрес; приватная ссылка Sites служит для просмотра владельцем.
