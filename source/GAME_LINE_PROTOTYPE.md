# Игровая линия по текущему преимуществу

Согласовано пользователем 06.09.2026 как отправная точка для будущего прототипа. Пока работа приостановлена: не устанавливать модели, не арендовать серверы и не запускать обучение на основании этого документа.

## Цель

Отражать наблюдаемое состояние боя сейчас, а не предсказывать будущего победителя. Коэффициенты — условная игровая шкала преимущества, не достоверные вероятности и не настоящая букмекерская линия. Используются виртуальные очки, без денежных ставок. В интерфейсе явно обозначать «Игровая AI-оценка».

## Разделение ответственности

Видео → распознавание действий и уверенности → состояние боя → отдельный алгоритм игровых котировок и приостановки линии.

Модель зрения распознаёт действия, а не самостоятельно придумывает числа. Алгоритм задаёт диапазон, плавность изменения, формат и условия закрытия. Формулы, пороги, частоту обновлений и качество распознавания ещё предстоит подобрать и проверить, они не согласованы как готовые параметры.

## Поведение

| Наблюдение | Реакция |
|---|---|
| Равный обмен | Близкие игровые коэффициенты |
| Явное преимущество одного бойца | Его коэффициент снижается, соперника растёт |
| Опасная серия, возможный нокдаун или остановка | Временно закрываются оба исхода; игровая ставка недоступна |
| Бой продолжается и ситуация снова понятна | Открыть линию после подтверждения состояния, с актуальной оценкой |
| Повтор, реклама, потеря видимости/идентичности бойцов, неуверенность или устаревшие данные | Приостановка; не выдумывать события |
| Подтверждённое завершение | Закрыть линию; расчёт только по подтверждённому результату |

- Различать попытки ударов, блоки и подтверждённые попадания. Количество взмахов не равно эффективности.
- Для борьбы различать попытку прохода, выполненный тейкдаун, последующий контроль и выход. Нужны размеченные примеры и проверка на новых боях.
- Формат чисел: два знака после запятой (1,85; 2,40). Это оформление, не обещание точности.
- Учитывать временные метки: оценка должна соответствовать показанному видео, не использовать будущие кадры. Для записей исключить подсказку исхода из будущих кадров/метаданных.
- Возможность ручного задания имён и отличительных признаков бойцов для первого теста.

## Использование открытых разработок

Кандидат: https://github.com/ACM40960/Boxing — прототип YOLO + LSTM для боксёрских действий. Пока не установлен и не проверен на наших видео. Сначала проверить код, зависимости, лицензии кода/весов/данных, затем испытать отдельно. Не считать готовым анализатором MMA или букмекерским движком.

Код можно подключить как модуль, веса — загрузить при совместимости, размеченные примеры — использовать для обучения при допустимых условиях. Просто положить репозиторий рядом с моделью не означает обучить её.
