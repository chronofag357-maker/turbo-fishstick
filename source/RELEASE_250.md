# Версия 250 — подробные карточки событий

По исследованным экранам Pari: компактная шапка участников, возврат к списку,
группы доступных рынков и отдельные вкладки статистики карт киберспорта.
Общая страница для бокса, MMA и esports, с сохранением наших цветов и купона.
Внутри можно вручную обновить бой или включить/остановить Live esports.

API-Sport: публичная проекция bestOf/games, статус/победитель/счёт карты,
длительность, kills/gold/towers/dragons/Baron при наличии в исходных данных.
Неизвестный счёт — тире, не ноль. В списке общий счёт и компактные счета карт.
Статистика карты не выдается за рынок ставок. Отдельные map markets и видео
не подключены: не подтверждены поставщиком. MMA/бокс сохраняют текущий
источник и исходы/тоталы, без выдуманной расширенной росписи Pari.

Исправлен обработчик WS scalar delta (ошибочная ссылка self в функции merge).
Поддержано обновление элементов массивов по индексам из дельт games.
Возврат не меняет аккаунт, фильтры и позицию списка; обновление сохраняет
выбранную карту, свёрнутые группы и прокрутку подробной карточки.

Проверки: 27 unittest backend, test_esports_ui, test_esports_live_ui,
test_event_details на 320/390. Только фикстуры, без расхода API на UI-тесты.
Проверка на настоящем телефоне — после публикации владельцем.
