# Версия 248 — Live-киберспорт

Кнопка «Обновить» включает серверный WebSocket API-Sport с withBkOdds=true.
Один upstream на процесс, heartbeat видимых клиентов, остановка по уходу,
пауза при сворачивании, повторное нажатие останавливает поток. Ключ только на сервере.
Суточный лимит приложения и прежняя пауза 30 минут сняты только для киберспорта.
Изменения реальных цен подсвечиваются без изменения геометрии ячеек.
Доступны учебные ординары и экспрессы, подтверждение изменённых цен,
серверная проверка, идемпотентность оформления и ручной расчёт администратором.
Закрытые и неподтверждённые устаревшие рынки нельзя оформлять.

Проверки: test_esports_feed, test_esports_live, test_esports_refresh_access,
test_miniapp_backend, test_miniapp_http; браузерные test_esports_ui и
test_esports_live_ui на 320/390 px. WebSocket проверен локальным тестовым сервером.
Поток настоящего поставщика не запускается при деплое: его включает пользователь.
