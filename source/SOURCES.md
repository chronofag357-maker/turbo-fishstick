## Реализация

- `source/tournament-sources.json`: точные пары, допустимые даты, ссылки, названия, режим источника.
- `bot/services/tournament_metadata.py`: обогащение ответа `/api/odds?sport=mma`.
- `.tools/tournament-metadata-cache.json`: автоматически создаваемый закрытый серверный кэш, исключён из Git.
- Время переводится в Europe/Moscow локально через Intl; отдельного API времени нет.
- Парсер BKFC не меняет даты боя и не угадывает новые пары. При смене даты/схемы или ошибке сохраняет прежнее название с признаком stale. Попытки также ограничены сутками.
- Новые турниры не обнаруживаются автоматически. Для этого нужен проверенный общий календарь/API с правом регулярного получения данных. Octagon API проверен: документирует бойцов и рейтинги, но не календарь.

## Ограничения достоверности

Не присваивать турнир по одной дате или одному бойцу. Далёкие даты в букмекерской линии могут не означать официально анонсированный кард. Оставшиеся неизвестные названия не заменять выдуманными. Наличие котировки не доказывает, что бой не отменён.

Обновление официального времени начала и автоматическое подтверждение всех стадий UFC пока не реализованы. Публикация на GitHub и публичный HTTPS также отдельные задачи.
