# TheSportsDB — бесплатный V1

Проверено 06.09.2026: https://www.thesportsdb.com/documentation#v1
Общий бесплатный ключ 123 опубликован провайдером, это не личный секрет.
V2 требует Premium; не используется и не оплачивался.
Бесплатный лимит по документации: 30 запросов/минуту, поиск событий —
до одного результата. Пустая выдача не подтверждает отсутствия боя.

Модуль bot/services/thesportsdb, кэш .tools/thesportsdb.json на 96 часов.
Первичная интеграция ограничена двумя проверенными поисковыми запросами
на сезон 2026, не всем боксом. Две успешные проверки HTTP 200:

| Бой | ID | Полезные поля |
|---|---|---|
| Ryan Garcia vs Conor Benn | 2548270 | Название, дата, описание, T-Mobile Arena, Las Vegas |

Дополнительная ссылка появляется в блоке при совпадении обоих имён,
лиги Boxing и даты с допуском один день. Время, пояса, раунды и цены
не перезаписываются. intRound=96/97 не число раундов боя. strTime=00:00:00
не используем как точное начало. Описания и изображения не публикуем
автоматически; наличие ссылки на изображение не определяет права использования.
Ошибки кэшируются вместе с последними данными; повторов при каждом открытии нет.
Папки разделяют ответственность, но сами по себе не замедляют ответы.
