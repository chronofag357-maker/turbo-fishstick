# Шрифты проекта

Документация, сохранённая по просьбе пользователя 08.09.2026:
https://developers.google.com/fonts/docs/getting_started?hl=ru

Выбран для примерки на стартовом логотипе Bitcount Prop Double Ink.
Файл и лицензия находятся в docs/fonts/bitcount/. Подключение через
локальный @font-face в docs/welcome.css, без внешних запросов при открытии.
Размер обеих строк 28 px, вес 700. Остальные оси — из присланного CSS.
Это цветной шрифт: в браузерной проверке буквы имеют разноцветный
точечный рисунок, несмотря на color: white. Белая версия не утверждена.

Предыдущий Archivo Black сохранён в docs/fonts/archivo-black/ для возврата.
Шрифты не установлены в Windows глобально. Google Fonts CSS API подключает
шрифты к веб-страницам, не добавляет клавиатуру или интерфейс выбора шрифтов.
Пожелание о выборе с клавиатуры нужно уточнить перед реализацией.
