# Цвета FreeBK

## Цвет для незаходов

По договорённости с пользователем: «цвет для незаходов», «незаходы» —
приглушённый тёмно-розовый **#98536F**.
Светлый фон: #FBF7F9. Фон метки: #F1E4EB.
Использовать этот цвет при будущих запросах про незаходы.
Это отдельное обозначение, не синоним отмены боя.

## Цвет для отмены

Салатовая гамма утверждена пользователем. Формулировки «цвет для отмены»,
«отмена» в запросах на оформление означают эту палитру.
Использовать при будущих запросах, не смешивать с цветом для незаходов.

Текст: #567A22 (тёмный салатовый для читаемости).
Акцент слева: #A3C85A. Фон: #F6FAED. Фон метки: #E6F0CD.
Пометка «Отмена» и блокировка коэффициентов сохраняются.

## Цвет для иконок и буфов

Утверждённый светло-зелёный **#70BD8B**.
Формулировки пользователя «цвет для иконок», «цвет для буфов» относятся
к этому оттенку. Сейчас применяется к иконкам и подписям активного
раздела «Единоборства» / «Бокс», без обводки.
Заменяет прежний тёмно-зелёный #246B50 для активного раздела.
Цвета отмены и незаходов выше остаются без изменений.

## Цвет для захода

Упомянут пользователем, но отдельный оттенок однозначно не утверждён.
Перед применением уточнить; не путать с цветом для незаходов.
