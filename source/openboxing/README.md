# Open Boxing — отдельный исследовательский источник

Проверено 06.09.2026. Документация: https://www.openboxing.org/api/

Веб-чтение https://openboxing.org/api/bouts/scheduled.json вернуло шесть
боёв с датами 25.07.2023–30.09.2023, всё ещё помеченных SCHEDULED.
Это устаревшая выдача, не актуальный предматч. Не подключать её к live-ленте.
Сайт сам предупреждает о ранней стадии разработки, ошибках и пропусках.

Локальное скачивание четырёх JSON завершилось HTTPError. Полные наборы
не скачаны: import-report.json фиксирует неуспех, а не успешный импорт.
download.py — ручной импортёр для повторной проверки обычного доступа;
защиту сайта он не обходит, автоматически не запускается.

| Данные | Поля / маршрут | Что можно сделать | Ограничения |
|---|---|---|---|
| Бои | bouts/all.json, bouts/scheduled.json | История встреч и пары | Предстоящие бои устарели |
| Вес | weight.class, weight.lb | Подписать категорию конкретного боя | Нельзя переносить старый вес на будущий бой |
| Раунды | scheduledRounds | Плановая дистанция боя | Не путать с result.totalRounds |
| Титулы | titles, org.name | Исторические пояса на кону | active не доказывает актуальность на сегодня |
| Результаты | winner, methodOfVictory, totalRounds | История побед и способов завершения | Проверять полноту и дату |
| Боксёры | championId, name, born | Имена, даты рождения, карточки | Это база чемпионов, не всех профессионалов |
| Чемпионские периоды | reigns/all.json, period | История владения поясами | current может быть устаревшим |
| Место | location | Арена, город, страна | В проверенном расписании значения null |
| Время начала | date | Календарный день | Часов и часового пояса в проверенных записях нет |
| Коэффициенты | Нет в описанной схеме | Не использовать | Остаются у The Odds |

Возможная польза — отдельные исторические карточки после сверки.
Права на повторную публикацию и актуальность всей базы дополнительно не проверены.
