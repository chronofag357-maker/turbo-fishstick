# AI-анализ боя и live-коэффициенты: первичный обзор

> Последующее решение пользователя: первый прототип отражает текущее преимущество условными игровыми коэффициентами, НЕ прогнозирует победителя. См. GAME_LINE_PROTOTYPE.md. Вероятностная архитектура ниже сохранена как исследовательский вариант, не как текущий план реализации.

Дата: 06.09.2026. Это исследование, не проверенное работающее решение. Репозитории не запускались, модели/данные не скачивались. Перед использованием проверять лицензии кода, весов и видео отдельно.

## Что подтверждают поставщики

- Sportradar Live Odds описывает математические модели и надзор трейдеров: https://sportradar.com/betting-gaming/betting/odds/?lang=en-us
- Документация UOF описывает scouts/operators, мониторинг события и закрытие рынков (bet stop): https://docs.sportradar.com/uof/data-and-features/markets-and-outcomes
- MMA API: live-результаты UFC/DWCS, не открытая формула расчёта вероятностей: https://developer.sportradar.com/mma/reference/mma-overview
- Нельзя заключать, что каждый букмекер считает UFC напрямую нейросетью с камер. Конкретная технология сбора UFC в этом обзоре не подтверждена. Коммерческие API данных/котировок не равны открытому коду их моделей.

## Предлагаемая собственная архитектура

1. Видео с разрешённым доступом и временными метками; определить бойцов, раунд/таймер, исключить повторы/рекламу.
2. Детектор и модель действий: отличать попытку прохода, завершённый тейкдаун, контроль, выход, удар/попадание/блок; сохранять уверенность.
3. Состояние боя + предматчевая оценка + время → обученная вероятностная модель. Никакого постоянного «+10% за тейкдаун».
4. Калибровка вероятностей на отложенных боях (Brier score/log loss); разделять выборки по боям, не соседним кадрам. Не давать будущие кадры/результат модели.
5. Десятичная условно честная котировка = 1/p. Если есть ничья, отдельно моделировать её вероятность; no contest/отмена — правила возврата, не автоматическая ничья. Маржа для учебного режима необязательна.
6. Отдельная логика игровых ставок: версия котировки, серверное время, синхронизация с показываемым видео, приостановка на важных/неясных событиях, итог по подтверждённому результату.

Начать с ручного ввода событий как проверяемого базового варианта, затем заменять его распознаванием. Результат сравнить с предматчевой оценкой и простыми статистическими моделями, прежде чем тратить деньги на дообучение большой VLM.
