# Киберспорт: отложенное подключение

## Обновление 10.09.2026 — Live по запросу владельца

Лимит приложения 10 REST-запросов/сутки и пауза 30 минут сняты только
для API-Sport. Двухсекундное объединение одновременных REST-обновлений и
пауза после ошибки — защита от дублей и сбоев, не тарифная квота.
При открытии вкладки читается кэш, поставщик не опрашивается.
«Обновить» запрашивает REST-снимок и включает серверный WebSocket:
sport:esports и подписки на текущие незавершённые матчи с withBkOdds=true.
Один upstream на процесс; API-ключ не выдаётся браузеру. Нормализуются
только котировки Pari. Блок букмекера в delta заменяется целиком.
Интерфейс забирает свежий снимок нашего сервера раз в 2 секунды, без REST-опроса
поставщика. Нет изменений цен — нет мигания. Закрытые рынки недоступны.
На сворачивании/pagehide/выходе отправляется stop; аварийный обрыв браузера
освобождает подписку по истечении аренды (12 секунд плюс цикл ожидания).
После обычного возвращения в видимую вкладку поток возобновляется; после
перезагрузки требуется новое нажатие. Повторное нажатие — явная остановка.

Купон поддерживает исходы/тоталы/форы и экспресс из разных матчей,
один исход на матч. Черновик сохраняется по текущему аккаунту, новые цены
требуют подтверждения. Сервер проверяет доступность и цену по свежему
REST-снимку (до 120 секунд) или подтверждённому снимку активного WS.
Оформление и расчёт остаются учебными, без отправки ставок букмекеру;
итоги подтверждает администратор по сохранённым вариантам исходов.

Источники протокола: https://docs.api-sport.ru/websocket/subscribe и
https://docs.api-sport.ru/websocket/snapshot-vs-delta . По документации
WebSocket не расходует REST dailyRequestLimit; ограничения самого тарифа
и доступность канала сохраняются. Реальная скорость определяется поставщиком.
Ниже — история прежних ограничений, заменённых этим решением.

## Обновление 09.09.2026 — API-Sport подключён локально

По новому запросу владельца добавлена вкладка «Киберспорт» в Mini App.
Поставщик: https://docs.api-sport.ru/ (не Odds-API.io).
Пробный ключ хранится в игнорируемом `.env.esports`, переменная API_SPORT_KEY.
Не копировать секрет в документацию, frontend или Git. Развёрнуто на VPS
09.09.2026 в релизе 247: секрет передан по SSH с правами 600, кэш отдельно
от Git. Проверка HTTPS вернула 146 сохранённых событий без нового запроса.

Проверка: киберспорт доступен; получены CS2, Dota 2, LoL. Betboom не отдал
линии в первой выборке. Выбран только Pari: 146 матчей на три дня,
68 с рынками в проверенном ответе. Это снимок покрытия, не постоянная гарантия.

Сервис `bot/services/esports_feed.py`: общий дисковый кэш в data/;
нет фонового обновления; ручное обновление не чаще 30 минут, бюджет 10
запросов/сутки на приложение, включая неудачные. Публичное чтение использует
кэш (первая загрузка создаёт его); принудительное обновление — после входа,
либо с loopback для локального предпросмотра. Размер страницы 500, три дня,
один букмекер; не обходить страницы автоматически. Остальные спорты не затронуты.

UI: расписание, дисциплины, прематч/live, исходы, тоталы, форы, раскрытие
полученных рынков. Пока только просмотр: киберспортивные купоны и расчёт
не подключены. Сохранённая линия не является гарантией доступности ставки.
Тесты: test_esports_feed.py, test_esports_ui.cjs (без запросов поставщику).
