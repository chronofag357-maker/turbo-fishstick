# Пиксельное появление букв

Утверждено пользователем 08.09.2026. Относится к анимации надписи,
не к авторизации или реальной загрузке API.

## Эффект

- Сначала чёрный терминал. Маленькие участки букв включаются в случайном
  порядке и остаются видимыми. Каждый сразу получает выбранную яркость:
  НЕ общий fade-in, не плавное увеличение opacity каждого участка.
- Сборка длится 5 секунд. После неё буквы неподвижны, рядом с последней
  буквой плавно мигает точка, по буквам идёт салатово-серебристый блик
  с циклом 3 секунды.
- Только во время сборки яркий рассеянный салатовый свет из-под плашки
  заполняет две половины контура одновременно: верхний левый угол →
  вниз → нижняя сторона → нижний правый; нижний правый → вверх →
  верхняя сторона → верхний левый. Пройденная часть остаётся.
  Два SVG path скрыты под чёрной поверхностью, виден внешний ореол.
  stroke-dashoffset 100 → 0 связан с тем же прогрессом, что и пиксели.
  Завершение отключает подсветку и перезапускает блик букв с нулевой
  задержкой; затем блик повторяется каждые 3 секунды.
- Учитывать prefers-reduced-motion: готовая надпись без сборки и обхода.
- Сохранять пользовательские настройки localStorage. Не объявлять
  браузерные значения записанными в проект без их фактического чтения.

## Реализация и повторное использование

Источник реализации: `docs/welcome.js`, блок Raster alpha mask.
Canvas 96×32 служит только прозрачной маской DOM-текста: перемешанные
ячейки закрашиваются белым без альфа-перехода через requestAnimationFrame.
Маска обновляется через data URL; после завершения снимается.
Сначала дождаться document.fonts.ready. Сам шрифт остаётся векторным.
Не заменять это анимацией opacity SVG-маски: в предыдущей браузерной
проверке такая версия показывала сразу целую надпись.

Стили: `docs/welcome.css`. Проверка: `test_welcome.cjs` (Playwright).
При повторном применении брать актуальную реализацию из этих файлов,
не поддерживать вторую копию. Не переносить стекло или форму входа,
если нужен только эффект букв.

## Проверка

Смотреть ранний и средний кадры, а не только финальный: должны быть
разрозненные яркие точки и ещё чёрные участки. Проверить завершение,
отключение контурного света, запуск блика, reduced-motion и 320/390 px.
Успешный тест входа не доказывает визуальную корректность анимации.
