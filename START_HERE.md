### Проверить самого бота, не останавливая локальный предпросмотр на 8081

```powershell
cd C:\Users\mars.la\turbo-fishstick
$env:PYTHONIOENCODING = "utf-8"
$env:MINI_APP_API_PORT = "8082"
.\.venv\Scripts\python.exe -m bot.main
```

Запускать только одну копию бота. Остановка Ctrl+C. Отправить `/start` заново.
Этот режим проверяет Telegram-бота, но кнопки Mini App пока ведут на старый публичный адрес.
Для новых экранов на телефоне сначала нужен рабочий публичный HTTPS-маршрут: устранение проблемы туннеля или согласованный VPS. Не отключать защиту TLS ради проверки.

## Бот с временным публичным адресом

```powershell
.\.venv\Scripts\python.exe start_bot.py
```

Запускает официальный cloudflared из .tools, проверяет доступ по HTTPS,
после успешной проверки запускает бота с новым адресом. .env не изменяется.
Терминал нужно держать открытым. Остановка: Ctrl+C.
После каждого запуска отправьте /start заново: ссылки в старых сообщениях
содержат предыдущий временный адрес. Это режим тестирования, не постоянный хостинг.

На проверке 05.09.2026 Telegram, LLM и Boxing Data API отвечали (3 боя).
Cloudflare Tunnel терял соединение и возвращал 1033/530; публичный доступ
пока не подтверждён. Для него требуется рабочий маршрут к Cloudflare или
постоянный сервер с HTTPS. Новый интерфейс в GitHub ещё не опубликован:
локальный Git не получил учётные данные для push.
