# FreeBK: продолжение работы

При изменениях Mini App прочитай `.agents/skills/freebk-ui/SKILL.md` и
`source/DESIGN_COLORS.md`. Это переносимые договорённости по интерфейсу;
новые явные пожелания пользователя могут их изменить.

Работать локально. Коммит, push и развёртывание на VPS выполнять только
по запросу пользователя. Не запускать второй polling-процесс Telegram-бота
для проверки HTML: локального веб-сервера достаточно.

Не переносить `.env`, ключи, базы и приватные кэши в Git.

Отложенный кандидат для киберспорта и решение пользователя:
`source/ESPORTS_PROVIDER.md`. Не подключать до нового запроса.
